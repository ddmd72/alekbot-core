Alek-Core

A multi-agent LLM exocortex.

01 / Memory

Not a chatbot. A system that remembers.

Every conversation produces facts: preferences, events, decisions, principles. Alek-Core extracts them in the background, deduplicates them against what it already knows, and uses them in every future answer. The more you talk to it, the less you have to explain.

02 / The cycle

The cycle

01 →

You speak.

A message arrives via Slack or Telegram. A router triages it: complexity, tone, what to search for.

02 →

It answers with context.

Memory and web search enrich the request. A model tier matching the difficulty answers: cheap for simple, strong for complex.

03 ↺

It learns.

A background agent turns the conversation into long-term facts. The next conversation already knows them.

facts from 03 feed step 02 of the next conversation

03 / Components

What's inside

a.

Multi-agent network

Router, Smart orchestrator, and specialists for search, email, tasks, documents, research, images and video, commissioned through one delegation tool.

b.

Long-term memory

Multi-vector retrieval with Reciprocal Rank Fusion, versioned facts with full history, number-aware deduplication (75 kg ≠ 84 kg).

c.

Provider-agnostic

Claude, Gemini, OpenAI and Grok are swappable per agent and per user, with complexity-driven model tiers.

d.

Voice

A phone call and a web call with a voice companion that shares the character and memory of the text assistant.

e.

Email as memory

Gmail is indexed passively; a daily review triages the inbox into an HTML report.

f.

Remote MCP server

Memory exposed to Claude as a custom connector (experimental).

04 / Engineering

Built to stay coherent under AI-assisted development.

Architecture

Hexagonal architecture enforced by 30+ AST-based tests, not by documentation.

Testing

6,500+ tests; contract tests validate the payloads sent to each LLM provider SDK instead of mocking the model.

Decisions

Decisions are recorded: 45+ RFCs and 90+ decision records.

Prompts

Prompts are data: assembled from versioned tokens at runtime, no inline fallbacks.
